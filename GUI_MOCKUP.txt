================================================================================
                              KEY FEATURES
================================================================================

LEFT PANEL - Document Tree:
  • Hierarchical view of all available documents
  • Checkboxes (☑/☐) for selection
  • Click individual files to select/deselect
  • Click folders to select/deselect all children
  • Scroll to see all documents
  • Organized by type (use-cases, state-machines, components, classes, reports)

RIGHT PANEL - Preview:
  • Shows markdown content preview
  • Updates when you select a file in the tree
  • Displays file path and selection status
  • Scrollable for long documents

CONTROLS:
  • Browse: Opens file dialog to select .qea file
  • Select All: Checks all documents
  • Deselect All: Unchecks all documents
  • Generate Selected Documents: Prompts for output directory, then generates

PROGRESS:
  • Status bar shows number of selected documents
  • Progress bar animates during generation
  • Success/error dialogs appear when complete

================================================================================
                            INTERACTION EXAMPLES
================================================================================

EXAMPLE 1: Select only use cases
  1. Click "Deselect All"
  2. Click the checkbox next to "☐ use-cases/" (selects all children)
  3. Click "☐ index.md" at root (for main navigation)
  4. Click "Generate Selected Documents"
  Result: Only use case files are generated

EXAMPLE 2: Select specific classes from one package
  1. Expand "classes/"
  2. Expand "domain/"
  3. Click individual class checkboxes (Order, User, etc.)
  4. Keep "classes/index.md" and "index.md" checked
  5. Click "Generate Selected Documents"
  Result: Only selected classes are generated

EXAMPLE 3: Preview before generating
  1. Click on "Login Use Case" in tree
  2. Right panel shows the markdown preview
  3. Review the content
  4. If satisfied, ensure it's checked
  5. Continue reviewing other documents
  6. Generate when ready
